# Augury Styleguide

Based on the "Fatherfog" reference materials.

## 1. Color Palette

The color scheme is tightly constrained, emulating a 2-color print process on colored paper. There are two primary thematic color sets used in the materials:

**The Green Set (Nature / Classic):**

- **Primary Background (Paper):** Pale Sage / Grey-Green (approx. `#e6e8e2`).
- **Secondary Background (Blocks/Tables):** Slightly darker grey-green (`#ced3cc`).
- **Primary Ink:** Charcoal / Soft Black (`#1c1e1d`).

**The Orange Set (Autumn / Warning):**

- **Primary Background (Paper):** Warm Rusty Parchment / Pale Orange (approx. `#dcb38a`).
- **Secondary Background (Blocks/Tables):** Darker rusty orange (`#c99b70`).
- **Primary Ink:** Very dark brown / Soft Black (`#2a1f1a`).

- **Highlights (Both):** Off-White / Cream. Used very sparingly within illustrations to indicate light sources or provide stark contrast. Not generally used for UI backgrounds.

## 2. Typography

The typography heavily leans into a medieval, gothic, and vintage book aesthetic.

- **Main Headings (H1):** Gothic / Blackletter style (e.g., _Cloister Black_, _Old English_, or an open-source web font like _UnifrakturMaguntia_). Should feel hand-drawn, slightly rough or distressed. Typically center-aligned.
- **Subheadings (H2, H3):**
  - Some use a cleaner but still bold Gothic font (e.g., for class names or section titles).
  - Others use a heavy, classic serif.
- **Section Labels (Headers/Superheaders):** Small, italicized, classic serif, often centered (e.g., "II. Character Creation").
- **Body Content:** Classic Old-Style Serif (e.g., _Garamond_, _Caslon_, _EB Garamond_, _Crimson Text_). Needs high legibility for long reading blocks.
- **Quotes / Flavor Text:** Italicized body font, often offset.
- **Drop Caps:** Highly ornate, illuminated manuscript-style initials. Spanning 3-4 lines of text, heavily detailed (vines, filigree, themed backgrounds).

## 3. Layout & Elements

- **Illustrations:** Woodcut or linocut style. Characterized by thick, rough lines, heavy hatching, and stippling. They should feel dark, moody, and rooted in dark fairytale/folklore.
- **Borders & Frames:** Heavy, hand-drawn borders encapsulate illustrations and sometimes entire page blocks. Borders often incorporate thematic motifs (thorns, twisting vines, bones, sigils, class emblems).
- **Dividers / Flourishes:** Ornate, symmetrical floral or filigree flourishes used to separate distinct sections of content.
- **Layout:** Two-column or single-column text layouts resembling a grimoire or classic TTRPG manual.
- **Tables & Lists:** Simple, utilizing minimal borders, with subtle shading for headers (using the green background palette). Bullet points are simple and unobtrusive.

## 4. Overall Vibe

"Fairytale Horror." The aesthetic is grim, rustic, and archaic. It should feel like an ancient, well-worn manual discovered in a damp forest. Avoid modern UI paradigms like soft drop shadows, large rounded corners, or bright neon accent colors. Everything should feel hand-crafted, tangible, and printed via physical press/woodblock.
